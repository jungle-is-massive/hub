01
Navigation — the eight pages

The hub uses a permanent left-hand icon strip (52px wide) that's present on every page. Hovering any icon shows an instant label — no tooltip delay. The active page is highlighted in green. Each section of the original single-page dashboard has been promoted into its own standalone page, so everything can be viewed, shared, and worked with in isolation.

Dashboard
activity-dashboard-v2.html
The default view. Stat cards, deal opportunity tracking, deal source breakdown, prospect funnel stages, and the momentum strip. No scrolling — everything fits the viewport.
Opportunities
opportunities-v2.html
Full Agency Pipeline in four views: Pipeline (kanban, drag-and-drop to update HubSpot), List (flat table), Timeline (Gantt with HubSpot task milestones), and 4-week (week-by-week milestone breakdown). New Opportunity and New Deal buttons create directly in HubSpot.
Priorities
priorities-v2.html
Full CRUD list of BD priorities, stored in Supabase. Three views: List (grouped by priority tier, drag-and-drop reorder), Timeline: Bars (Gantt), and Timeline: Calendar (month grid). Filter by priority (High/Medium/Low/Ongoing/Blocked) and category (Marcomms/New Biz/Marketing).
News Desk
share-queue-v2.html
Five-lane kanban (Idea → Drafted → Approved → Scheduled → Sent) for staging content going out to intermediaries. Coris and Ro both contribute. Two tracks: Digest (monthly HubSpot email) and Personal 1:1 (WhatsApp or email). Quick-add presets for Award win, Client win, Pitch invite, Commercial result.
Prospects
prospects-v2.html
Eight tabs: All contacts, LinkedIn, Dripify, Target Prospects, Inbound, Referral, Personal, and MAD Meets. MAD Meets tab shows live HubSpot lead status, last contacted date, last email communication pulled from HubSpot, and an email compose modal with three templates. Email sends via Gmail API with automatic HubSpot BCC.
Meetings
meetings-v2.html
BD meeting log. Upcoming (next 30 days) and Attended (last 30 days) tabs. Pulls live from Google Calendar when connected — any event with #nbm (New Business) or #netm (Network) in its description. Falls back to Supabase-cached data synced by whoever last connected, with a sync timestamp shown.
Inquiries
inquiries-v2.html
Three-column view of BD-flagged inbound inquiries from Supabase. Select an inquiry to read the full message (enriched from HubSpot if available), update the HubSpot lead status (saves live on change), and add notes that are written back to HubSpot as activity log entries.
Events
events-v2.html
Industry events calendar from Supabase. Upcoming and Past tabs. Category pills: Intermediary (blue), Speaking (purple), Attendance (green), Owned Event (orange). Content and Nurture category events are filtered out — BD-relevant events only.
02
Data sources

The hub pulls from four systems. HubSpot is the authoritative source for all pipeline, deal, and contact data. Supabase is Jungle's own database — it stores priorities, the share queue, events, Dripify contacts, and serves as the proxy layer for HubSpot API calls. Google Calendar feeds meeting data. Dripify connections sync into Supabase automatically via Make.com.

HubSpot
CRM · Primary source
The sole source of truth for contacts, lifecycle stages, deals, notes, and email history. The hub queries HubSpot via a Supabase edge function proxy (hs-proxy) to avoid CORS issues. All deal queries are scoped to the Agency Pipeline only (2808364263). Contact lifecycle stages power the Prospect Funnel. The MAD Meets tab reads live lead status and email threads from HubSpot.
Supabase
Database · Multiple tables
Jungle's own Postgres database. Stores: growth_status (Priorities CRUD), share_queue (News Desk kanban), events (industry events), contacts (all non-Dripify contacts), prospects (Dripify connections), bd_meetings (cached GCal BD meetings), hubspot_enquiries (flagged inbound inquiries), funnel_stages (funnel stage definitions). Project ref: iehkvlyjumkzccoqqgxl.
Google Calendar
GCal · OAuth 2.0
Powers the Meetings page. Uses OAuth 2.0 implicit flow — you connect by clicking "Connect Google Calendar" on the Meetings page. The token is stored in localStorage and lasts one hour. When connected, the page reads directly from the primary calendar. When not connected, it falls back to meetings cached in Supabase by the last person who connected. Tags: #nbm (New Business meeting) and #netm (Network meeting) must appear in the event description.
Dripify
LinkedIn outreach · via Make.com
LinkedIn outreach connections sync automatically into the prospects table in Supabase via a Make.com scenario. New Dripify connections appear in the Prospects page under the Dripify tab. The Make.com automation runs on a schedule — new connections may take up to a few hours to appear.
📌
The discipline: if an opportunity isn't logged in HubSpot, it won't appear on the dashboard. Every deal needs to move through the Agency Pipeline for the numbers to be accurate. Synergist was previously used for deal data but has been removed — it was causing double-counting. HubSpot is the only source of pipeline truth.
03
Dashboard — stat cards & charts

The default view. Clicking a stat card navigates to the relevant standalone page rather than scrolling down (Meetings → meetings-v2.html, Inquiries → inquiries-v2.html, Open Deals → opportunities-v2.html). The body sections that previously lived on the dashboard (Meetings, Inquiries, Open Deals Now/Next/Future, Events) have been moved to their own pages.

CardSourceWhat it countsFilter
Open Dealsstat-deals HubSpot Total open deals in the Agency Pipeline Excludes Closed Lost, Closed Won, and Declined. Agency Pipeline only.
Active Pipelinestat-pipeline HubSpot Total £ value of open Agency Pipeline deals vs £6m target (3:1 on £2m revenue target) Same deal set as Open Deals. Progress bar = % of £6m target covered.
Fresh Inquiriesstat-inquiries Supabase BD-flagged inbound inquiries Rows in hubspot_enquiries where bd_flagged = true. Clicking navigates to the Inquiries page.
Meetingsstat-meetings Google Calendar Upcoming (next 30 days) and attended (last 30 days) tagged meetings Events with #nbm or #netm in description. Falls back to Supabase cache when GCal not connected.

Deal Opportunity Tracking — the seven boxes below the stat cards. Warm, Qualified, Pitch/Proposal, and Contracts map to active Agency Pipeline stages. Won, Lost, and Declined run separate queries because they're excluded from the main active deals fetch.

Deal Source breakdown — colour-coded pills, one per source, with a live deal count. Deals with no source show as "Untagged". The Intermediary pill is clickable and expands the Intermediary Pipeline comparison table below it.

Prospect Funnel Stages — six boxes counting HubSpot contacts by lifecycle stage. These are contacts, not deals — a different object type. The stage structure is defined in Supabase (funnel_stages table) and counts fetch live from HubSpot one request per stage.

Momentum strip — the black bar below the stat cards. Summarises week-on-week deltas: deals that left pipeline, change in pipeline value, meetings attended, and meetings booked ahead.

05
Priorities — CRUD list & timeline

A managed list of BD priorities stored in Supabase (growth_status table). Every item can be created, edited, and deleted directly in the page — no Supabase UI needed. Changes write back to Supabase in real time.

FieldNotes
Priority tierHigh / Medium / Low / Ongoing. Controls the group the item appears in on the list view. Ongoing is collapsed by default — it's a "parked, check in periodically" category.
CategoryMarcomms / New Biz / Marketing. Used for the category filter chips in the toolbar.
Dates / milestonesMultiple dated entries per item (date + label). Power the Timeline bar and calendar views. Adding a milestone: open the item → Add date.
StatusFree-form status label (In progress, Scheduled, Reviewing, etc.). Shown as a colour-coded pill on list cards.
BlockersAny content here causes the ⚠ indicator to appear on the card. The "Blocked" filter chip shows all items with blockers set.
OwnerFree text. Shown on the card.

Drag-and-drop reorder — drag cards within or between priority groups on the list view. Order is saved to Supabase via display_order field. Moving to a different group also updates priority_tier in Supabase.

Deep-linking — the URL updates to reflect the active view (#priorities/timeline, #priorities/timeline/calendar). Sharing the URL takes the recipient directly to that view.

06
News Desk — share queue

The staging board for content going out to intermediaries. Based on the insight from an independent intermediary contact that informal, bullet-point updates are genuinely welcomed — they don't need to be finished case studies. Both Coris and Ro contribute to this board.

LaneMeaning
IdeaSomething worth sharing — not yet written up.
DraftedWritten. Needs review before it goes out.
ApprovedReviewed and signed off. Ready to schedule or send.
ScheduledAssigned a send date in the item form.
SentGone. Timestamp recorded at the point of moving here.

Two tracks: Digest (goes into the monthly HubSpot email to intermediaries) and Personal 1:1 (a direct WhatsApp or email to a specific person or group). The track and channel are set on the item card. Time-sensitive proof items (wins, awards, pitches) default to the Personal 1:1 / WhatsApp track.

Audience tagging: eight named intermediaries (Ingenuity, AAR, Oystercatchers, Creativebrief, Observatory International, Tuffon Hall, Elevator, Masterclassing) plus group tags (All intermediaries, Clients, Prospects, Press/media). An item can be tagged to multiple audiences.

Copy for sending: the "Copy for sending" button inside an item formats the headline, bullets, and source link into a clean paste-ready message for WhatsApp or email.

Prospects — contacts & MAD Meets

The full contacts database across all sources. Eight sub-tabs. All tabs except MAD Meets pull from Supabase and are searchable by name, company, or title. The MAD Meets tab is different — it's a curated list of contacts from the Ingenuity MAD Meets events with live HubSpot enrichment.

Email compose modal: available on any contact with an email address. Three pre-built templates (Chaser, Meeting follow-up, Check-in) pre-fill with the contact's first name and company. Emails send via Gmail API (googleapis.com/gmail/v1/users/me/messages/send) and are automatically BCC'd to HubSpot (145756322@bcc.eu1.hubspot.com) so they appear in the contact's activity timeline. Requires Google to be connected — same OAuth scope as Meetings but scoped to gmail.send.

08
Meetings — GCal BD log

Tracks BD meetings using Google Calendar as the source. Two tabs: Upcoming (next 30 days) and Attended (last 30 days). Each card shows the date, time, title, attendees, and the event description (stripped of the tag).

TagMeaningCard colour
#nbmNew Business Meeting — a commercial conversation with a brand or prospectGreen pill — "New Business"
#netmNetwork Meeting — relationship building, not an active pitchBlue pill — "Network"

Tags must appear in the event description (not the title) in Google Calendar. The page strips the tag from the displayed description.

Cached fallback: when GCal is not connected, the page reads from the bd_meetings table in Supabase. This table is populated whenever someone connects their calendar — the sync timestamp and name of whoever last synced is shown below the tabs.

OAuth note: the page uses Google's OAuth 2.0 implicit flow. The redirect URI must be registered in Google Cloud Console. If you're seeing a redirect_uri_mismatch error on a new page URL, the URL needs to be added as an Authorised Redirect URI in the Google Cloud Console credentials for this OAuth app.

09
Inquiries — inbound BD flags

A three-column view of inbound inquiries that have been flagged as BD-relevant. The flagging happens in the original activity dashboard's Fresh HubSpot Inquiries section. Once flagged, the inquiry appears here.

ColumnWhat it shows
List (left)All BD-flagged inquiries from Supabase (hubspot_enquiries where bd_flagged = true), sorted by flag date descending. Click to select.
Message (centre)The full inquiry message. If the Supabase record has no message body, the page fetches it from HubSpot using the contact's email address and shows the HubSpot message field instead.
Status & Notes (right)Lead status dropdown — updates HubSpot on change (600ms debounce). Latest dashboard note shown (any HubSpot note tagged [Activity Dashboard Note]). Add new note field — saves to HubSpot as an activity note associated with the contact, and updates the Latest Note block inline.

Known gaps & next steps

Things that are intentionally deferred, pending a decision, or blocked on configuration.

  • SQL (box 03) shows 0 — No contacts are tagged as Sales Qualified Lead in HubSpot. Accurate — the criteria and process for moving contacts from MQL to SQL hasn't been defined. Needs a working definition before the number will move.
  • Nurturing (box 06) always shows — — No HubSpot lifecycle stage mapped yet. Can be added as a custom lifecycle stage in HubSpot Settings → Objects → Contacts → Lifecycle Stage when the team is ready to track this cohort separately.
  • HubSpot Contact ID deduplication not yet implemented — The agreed approach for deduplicating Supabase intermediary_people records against HubSpot is to store the HubSpot contact ID back in Supabase. This is designed but not yet built.
  • WhatsApp Business API for direct sends not yet wired — The plan is to send News Desk Personal 1:1 items directly from the hub via Make.com + 360dialog or Twilio. Currently the "Copy for sending" button is the workaround.
  • HubSpot digest track not yet connected to News Desk — Items in the Digest track on the News Desk are intended to feed into a monthly HubSpot email sequence. The connection between the share_queue table and HubSpot email is not yet built.
  • Jungle Sales Pipeline not tracked — Deals in the default Jungle Sales Pipeline are not shown anywhere on this hub. Deliberate decision as of May 2026 — the hub focuses on Agency Pipeline. To be revisited if the pipeline setup changes.
  • Navigation restructured — resolved June 2026 — The original single-page dashboard has been split into eight standalone pages with a shared left-hand icon nav. Meetings, Inquiries, Open Deals (Now/Next/Future), and Events have been promoted out of the dashboard body into their own pages.
  • Closed Won and Declined stages — resolved May 2026 — Closed Won (5277858030) and Declined (5277854954) added to Agency Pipeline on 1 May 2026. Both now show live counts on the Dashboard and appear as columns on the Opportunities Pipeline view.
  • Double-counting in pipeline value — resolved — Dashboard previously pulled open deals from both Synergist (Now lane) and HubSpot (Next/Future lanes), causing inflated pipeline value. All deal data now comes exclusively from HubSpot Agency Pipeline.
